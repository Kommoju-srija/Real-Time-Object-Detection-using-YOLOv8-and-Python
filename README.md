# Real-Time Object Detection using YOLOv8-and-Python

## 📌 Project Overview
This project demonstrates **real-time and image-based object detection** using  
**Python, YOLOv8, OpenCV, and Google Colab**.

The system automatically detects and labels objects such as:
- Person
- Car
- Mobile Phone
- Laptop
- Book
- Bottle
- TV and many more everyday objects

Each detected object is displayed with a **bounding box and label**.

## 🚀 How to Run (Google Colab)

1. Open Google Colab  
2. Upload `Object_Detection.ipynb`
3. Run all cells step by step
4. Upload any image (car, person, mobile, book, etc.)
5. The system will automatically:
   - Detect objects
   - Draw bounding boxes
   - Display object names

---

## 📸 Sample Output
- Car → car
- Human → person
- Mobile → cell phone
- Book → book

Each object is highlighted with a bounding box and label.
