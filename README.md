Real-Time Object Detection using YOLOv8 and Python

(Image-based Detection using Google Colab)

📌 Project Overview

This project demonstrates image-based object detection using Python and YOLOv8 (Ultralytics), implemented and executed in Google Colab.

Users can upload images, and the system automatically detects and labels multiple objects present in the image using a pretrained YOLOv8 model.

🔍 Objects Detected

The model can detect common everyday objects such as:

Person

Car

Mobile Phone

Laptop

Book

Bottle

TV

And many more COCO dataset objects

Each detected object is highlighted with a bounding box and label.

🧠 Technologies Used

Python

YOLOv8 (Ultralytics)

Google Colab

Jupyter Notebook

(Note: Webcam-based real-time detection is not implemented in this version.)

🚀 How to Run (Google Colab)

Open Google Colab

Upload Object_Detection.ipynb

Run all cells step by step

Upload any image (car, person, mobile, book, etc.)

The system will automatically:

Detect objects

Draw bounding boxes

Display object labels

📸 Sample Output

Car → car

Person → person

Mobile → cell phone

Book → book

Each object is displayed with a bounding box and confidence label.
